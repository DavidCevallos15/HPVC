# HPVC UI/UX SKILL DEFINITION

## 1. Identidad Institucional
- Paleta: Azul Marino (#003A70), Verde MSP (#007A4D), Gris Pizarra (#475569).
- Prohibición: 0% Emojis. Uso exclusivo de `lucide-react`.
- Tipografía: Limpia, profesional, jerarquía clara.

## 2. Motion & Interacción
- Curva: `ease-out`.
- Duración: 150ms a 300ms (Estricto).
- Comportamiento: Las tarjetas deben elevarse ligeramente al hover y usar opacidad suave.

## 3. Layout: Bento Grid
- Estructura: Cuadrícula modular asimétrica.
- Radios: `rounded-2xl` o `rounded-3xl` para un look moderno.
- Espaciado: `gap-6` para respiración visual.

## 4. Accesibilidad (WCAG AA)
- Contraste: Mínimo 4.5:1.
- Touch Targets: Mínimo 44x44px para navegación móvil.
